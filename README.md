Running 'make' creates two .txt files, 'makefileone' and 'makefiletwo.' 'makefileone.txt' contains simple phrases outputed by 'makefileone.py' and 'makefiletwo.txt' contains a series of simple math problems solved and outputed by 'makefiletwo.py'.
Running 'make clean' deletes both 'makefileone.txt' and 'makefiletwo.txt' files from the directory.
